# Engineering task template

```text
Goal:
[Describe one observable outcome.]

Context:
- Entry points:
- Reproduction or evidence:
- Related implementation:
- Applicable ticket/design/spec:

Constraints:
- Scope:
- Compatibility:
- Architecture:
- Safety and permissions:
- Explicitly out of scope:

Done when:
- Behavior:
- Focused tests:
- Required repository checks:
- Review expectations:

Process:
1. Inspect applicable AGENTS.md and current working-tree changes.
2. State assumptions that materially affect the solution.
3. Plan first only if the task is ambiguous or cross-cutting.
4. Implement the smallest coherent change.
5. Verify, inspect the diff, and report residual risk.
```

Delete empty fields rather than leaving ambiguous placeholders in a real task.
