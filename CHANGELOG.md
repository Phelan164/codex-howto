# Changelog

Notable changes to Codex How To are recorded here.

The project follows [Semantic Versioning](https://semver.org/) for published
learning packages. Version numbers describe the repository content, not Codex
product compatibility.

## Unreleased

- Add a community launch kit and structured feedback paths.
- Add a reusable social preview asset.

## 0.2.0 - 2026-07-31

- Add the end-to-end `engineering-loop` skill.
- Add lightweight skill routing and explicit invocation policies.
- Add hard-debugging, review, orchestration, and context-budget references.
- Add a dependency-free engineering playground with seeded defects.
- Add a paired-run measurement protocol, example data, and summary utility.
- Refine the README around observable engineering outcomes.

## 0.1.0 - 2026-07-24

- Publish the initial 13-module Codex curriculum.
- Add engineering skills for frontend, backend, DevOps, testing, code review,
  security review, and orchestration.
- Add starter configuration, agents, prompts, templates, hooks, and plugin
  examples.
